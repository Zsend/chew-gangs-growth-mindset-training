# Chew Gang's Growth Mindset Training

A single-page static website for kids to learn growth mindset, watch the embedded video, take a quiz, unlock a bonus 1% Better lesson, and print/save a certificate of completion.

## Files

- `index.html` — the complete website. Upload this at the root of the GitHub repository.
- `README.md` — this note. Optional, but safe to upload.

## Publishing on GitHub Pages

1. Create a new public GitHub repository named `chew-gangs-growth-mindset-training`.
2. Upload `index.html` and `README.md` to the root of the repo.
3. Go to `Settings → Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Set `Branch` to `main` and folder to `/ (root)`.
6. Save.
7. Your site should publish at `https://zsend.github.io/chew-gangs-growth-mindset-training/`.

## Important

Do not upload these files into `AzroTest` unless you are intentionally using the test site. This training site should live in its own repo.
